\subsubsection{Salient Spatial Token Selection}
\label{sec:method:video:spatial}

Rather than treating all patch tokens equally, SSTS learns a per-frame saliency prior that
concentrates on the informative patches.
Given the class token $\mathbf{c}_t$ and the patch tokens $\mathbf{P}_t$ of frame $t$, SSTS first
scores every patch from two complementary views.
The local view rates a patch by its own content alone, while the global view rates it jointly with
the class token.
Both views are lightweight MLPs shared across patches, yielding per-patch score vectors
\begin{equation}
  \tilde{\boldsymbol{\omega}}_t^{\mathrm{loc}} = f_{\mathrm{loc}}\!\big(\mathbf{P}_t\big),\qquad
  \tilde{\boldsymbol{\omega}}_t^{\mathrm{glob}} = f_{\mathrm{glob}}\!\big([\mathbf{P}_t;\,\mathbf{c}_t]\big)
  \;\in\;\mathbb{R}^{N},
\end{equation}
where $\mathbf{p}_{t,i}$ is the $i$-th patch token and $[\cdot\,;\,\cdot]$ concatenates the class
token with each patch.
Then the summed scores are reshaped into the $\sqrt{N}\times\sqrt{N}$ patch grid and smoothed by a
$3\times3$ convolution $f_{\mathrm{conv}}$, so that neighboring patches exchange importance
and no isolated patch keeps an aberrant score.
The smoothed map is flattened back to per-patch scores,
\begin{equation}
  \tilde{\boldsymbol{\omega}}_t = f_{\mathrm{conv}}\!\big(\tilde{\boldsymbol{\omega}}_t^{\mathrm{loc}} + \tilde{\boldsymbol{\omega}}_t^{\mathrm{glob}}\big)
  \;\in\;\mathbb{R}^{N}.
\end{equation}
Second, SSTS converts the scores into per-patch weights through a sigmoid gate, which keeps a
patch's importance graded rather than all-or-nothing,
\begin{equation}
  \boldsymbol{\omega}_t = \sigma(\tilde{\boldsymbol{\omega}}_t) \;\in\;\mathbb{R}^{N}.
\end{equation}
We normalize the weights over the patches wherever they are used as a distribution.
Third, SSTS keeps only the most salient patches and folds them into the class token, so that the
redundant background cannot dilute the aggregated context.
A top-$K$ mask
$\bar{\boldsymbol{\omega}}_t\in\{0,1\}^N$ sets the $K$ largest entries of
$\tilde{\boldsymbol{\omega}}_t$ to one and the rest to zero, with $K$ a fraction of $N$.
The masked weighted sum produces the saliency-aware frame token
\begin{equation}
  \tilde{\mathbf{c}}_t = \mathbf{c}_t + \alpha\, f_{\mathrm{mod}}\!\Big(
  \frac{\sum_i \omega_{t,i}\, \bar{\omega}_{t,i}\,\mathbf{p}_{t,i}}{\sum_i \omega_{t,i}\, \bar{\omega}_{t,i}}
  \Big) \;\in\;\mathbb{R}^{D},
\end{equation}
where $\omega_{t,i}$ and $\bar{\omega}_{t,i}$ are the $i$-th entries of $\boldsymbol{\omega}_t$ and
the top-$K$ mask, and the fraction is a weighted average over the selected patch tokens.
$f_{\mathrm{mod}}$ projects it to the
token dimension and $\alpha$ is a learnable scalar controlling the modulation strength.
For each frame, SSTS outputs the spatial weights $\boldsymbol{\omega}_t$ and the
saliency-aware frame token $\tilde{\mathbf{c}}_t$, which replaces $\mathbf{c}_t$ as the input to
KPTF.
SSTS reads nothing but a class token and a set of patch tokens of width $D$, and never inspects the
backbone that produced them.
This makes the operator reusable for any student whose output can be placed in the same token space,
which we exploit in \S\ref{sec:method:distill}.
